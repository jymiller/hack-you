1 · Pure function, injected clock

×6 · src/kernel/*.ts
export function assess(facts, cov, cert, memory, ctx) {
  const now = ctx.now;   // never Date.now()
  const order = ctx.precedence_override
              ?? facts.basis_precedence;
  // no I/O, no globals, no writes
}

Every input a parameter; the only clock is ctx.now. Referentially transparent.

2 · Total function (errors[], never throws)

×1 primary · assess.ts
if (rc.error) return indeterminate(
  facts, cov, period, now, rc.error,
  "Ratio unresolved", null,
  { basis, ratio, drift }   // keep what resolved
);
// INDETERMINATE ≠ silent PASS

A data fault yields a Finding with a typed code, not an exception.

3 · Resolver with tiered fallback

×1 · recompute.ts
// 1 clean measure → 2 reconstruct build
// → 3 stale (raise drift) → 4 unresolved
if (m && m.value != null
    && state === "observed"
    && m.raw_name != null)
  return { value: m.value,
           source: "measure" };

Decides when to trust an extracted value vs. rebuild — the drift boundary.

4 · One comparator via direction

×1 · classify.ts
headroom = dir === "max"
  ? threshold - value   // leverage ceiling
  : value - threshold;  // cover floor
// headroom < 0  ⇒  BREACH

One code path serves both metric families — no per-metric branching.

5 · Capability-object gate

×1 · attest.ts
function executeCommitted(
  w: CommittedWrite, ...): ServeReceipt
// only attest()@ATTEST builds a
// CommittedWrite → no serve without
// a human, enforced by the type.

The one side-effect is unreachable without a token only the human gate mints.

6 · API client with labeled fallback

×4 · youcom.ts
if (!key) return fallback(...);   // labeled
try {
  const d = await fetchJson(host, ...);
  return { label: "LIVE", ... };
} catch { return fallback(...); } // PRERUN/SYNTHETIC

Never hangs; the honesty label flips honestly on fallback.
