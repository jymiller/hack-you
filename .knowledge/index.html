What it is

The one truth on screen

Covenant Sentinel (repo hack-you) watches the live web for events that threaten a borrower's financial covenant, does cited deep research via the You.com Research API (ARI), recomputes the covenant ratio on its own books, and — only after a human attests — issues a reservation-of-rights breach notice to the covenant register. The killer failure mode it catches: a borrower quietly restating its accounts so a covenant silently breaches while the dashboard stays green. All borrower data is SYNTHETIC; the kernel is a pure, deterministic, offline function.

Why this KB

Two audiences, one source

Every fact here is authored in Markdown with structured YAML frontmatter (for AI agents) and rendered as this self-contained HTML with diagrams (for humans). The HTML is always derived from the Markdown — never hand-edited. Migration metadata (coupling, testability, extractability) lives in the same frontmatter that describes what each module does, so it can't drift.

Design constraints & how to maintain this knowledge base
  • MD is source of truth. Edit the .md files; the HTML portal and diagrams are derivatives. Serve the MD with node .knowledge/_server.js.
  • Frontmatter schemas validate structure. Six JSON schemas live in _schema/ (atlas, module, card, service, decision, migration).
  • Self-contained HTML. All CSS + SVG is inline; no CDNs. Works offline, over file:// or http://.
  • Relative links only. Never absolute paths, so navigation works both ways.
  • Progressive disclosure. 30,000 ft (this portal + atlas) → 5,000 ft (domain maps) → ground level (per-file cards).
  • To update: re-read the changed source, edit the relevant map/card/decision MD, keep the frontmatter valid, then reflect any structural change here.

System architecture

A deterministic, offline core wrapped in the You.com vendor face, gated by a human attestation, and served by a single Express app that auto-mounts drop-in demos. No LLM and no network sit in the money-shot.

TypeScript strict · ESM tsx no build step Express 4.21 (the only framework) vitest 51 assertions You.com Search + ARI Render single web service 0 databases · JSON on disk
